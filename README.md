# AI Resume Skill Gap Analyzer
### By Didla Akshaya

This project analyzes a resume and compares it with Job Description to find the skill gap.

### Tech Stack
- Python, FastAPI, PyPDF2, HTML

### Features
- Upload Resume PDF
- Paste Job Description
- Calculates Match Percentage
- Shows Missing Skills & Roadmap

### How to Run
pip install fastapi uvicorn PyPDF2
uvicorn app:app --reload

### Project Link
http://127.0.0.1:8000
